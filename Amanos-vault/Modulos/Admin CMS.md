# Admin CMS

Panel interno para cargar señas, videos y validaciones, y ver métricas del piloto. Usa la misma tabla de señas que el diccionario.

## Requerimientos funcionales
| Código | Requerimiento | Prioridad |
|---|---|---|
| RF-37 | CRUD de unidades y señas | Must |
| RF-38 | Subir videos de referencia por seña | Must |
| RF-39 | Registrar validador y fecha de validación | Should |
| RF-40 | Generar y guardar keypoints de referencia al subir video | Must |
| RF-41 | Métricas por usuario: dominadas, última sesión, días activos, finalización | Should |
| RF-42 | Exportar métricas a CSV | Could |

## Historias de usuario
- #12 CMS para subir señas (Must, 4 días)
