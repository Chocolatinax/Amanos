# Stack

| Capa | Tecnología | Nota |
|---|---|---|
| Front | Next.js + TypeScript + Tailwind | PWA con next-pwa |
| Cámara e IA | MediaPipe Hands/Holistic + TensorFlow.js | Todo en el cliente, no se sube video |
| Back | NestJS + PostgreSQL (Prisma) | Google OAuth + JWT |
| Pagos | Stripe Billing | Alternativa local: Wompi |
| Video | Cloudflare Stream | Videos de referencia de señas |
| Hosting | Vercel (front) + Railway o AWS (API y DB) | |
