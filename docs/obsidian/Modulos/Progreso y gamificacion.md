# Progreso y gamificacion

Dashboard de avance y motivación. Señas dominadas sobre 100, racha, XP, hitos.

## Requerimientos funcionales
| Código | Requerimiento | Prioridad |
|---|---|---|
| RF-25 | Dashboard: señas dominadas /100, % por unidad, racha | Must |
| RF-26 | Gráfico de avance semanal | Should |
| RF-27 | Estimar tiempo restante según ritmo | Could |
| RF-28 | XP por lección y por seña dominada | Should |
| RF-29 | Hitos a 10, 30, 50 y 100 señas | Should |
| RF-30 | Insignias por racha de 7 y 21 días | Could |
