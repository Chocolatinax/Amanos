# Amanos, Web App

Mapa de contenido de la web app para aprender LESSA. Lo que se cobra es la corrección por cámara, el contenido es gratis.

## Decisiones fijas
- Web app PWA, sin app nativa por ahora
- Solo LESSA (ASL después)
- Un solo plan de pago: $5/mes
- Paywall en la cámara, nunca en el contenido
